## 2. 应用处理哪些信息

大学生工具组是一款本地优先的 Windows 桌面应用。用户可以主动输入或导入以下学习资料：

- 日程、课程、考试、实验和成绩；
- GPA 公式、学期起始日期、提醒和免打扰设置；
- 主题、外观、通知历史和用户主动选择的背景图。

这些内容默认保存在本机应用数据目录。应用不要求用户创建本应用账号。

## 3. 教务系统导入

当用户主动打开教务导入功能时，应用会在隔离的远程页面中加载用户指定的教务系统。用户本人在该页面输入账号信息并完成登录；应用的主页面不会向开发者接收或保存这些密码。

导入功能优先解析页面 DOM。只有用户明确安装并使用 OCR 组件时，应用才会下载固定版本的本地 OCR 语言数据并在本机识别。OCR 组件在本机运行，不把识别内容发送给 OCR 服务。导入窗口关闭、取消或完成后，应用会尝试清理临时页面的 Cookie、缓存、网页存储和远程视图。

用户仍应在提交前检查教务系统的隐私规则、学校的使用规定和导入结果。不要把教务账号、密码或可复用登录会话提供给开发者。

## 4. 备份和共享

应用可以导出 v2 ZIP 备份。备份可能包含课程、日程、考试、实验、成绩、GPA 公式、通知历史、主题、学期设置和用户选择的背景图。

备份目前未加密。备份不包含应用密码、教务 Cookie、登录会话、浏览器缓存、窗口坐标、机器绝对路径、更新缓存或 OCR 组件。用户应只把备份保存或发送给可信对象，并在不再需要时安全删除。

## 5. 应用不会主动向开发者上传的内容

当前应用设计没有面向开发者的账号系统、广告 SDK 或学习数据同步服务。应用不以开发者服务器为中转保存课程、考试、成绩、密码或教务 Cookie。Microsoft Store 的安装、分发、更新和其自身可能收集的数据由 Microsoft 的相关隐私声明另行管辖。

为避免误解：操作系统、Microsoft Store、用户访问的教务系统、GitHub Release 下载服务及网络运营商可能按照各自政策处理网络请求或技术日志；本政策不替代这些第三方政策。

## 6. 保存期限和删除

本地学习数据、设置和背景图会保留到用户在应用中删除、导入覆盖、清理应用数据或按照 Windows 的卸载/存储管理规则处理为止。导出的备份文件由用户自行控制，其保留期限取决于用户保存位置和备份策略。

Microsoft Store 卸载是否保留用户数据取决于 Windows/Store 的实际行为；用户在卸载前应先导出备份。正式发布前，发布者应在目标 Windows 版本上验证卸载和重装行为，并在此处更新明确说明。

## 7. 安全措施和限制

应用使用本地数据库、输入校验、隔离的远程导入视图、受限协议和备份完整性检查降低风险。但任何本地文件、未加密备份、操作系统账户或第三方网站都不能保证绝对安全。用户应使用受支持的 Windows 更新、设备锁和可信存储位置。

## 8. 隐私请求

如果你需要访问、更正或删除由运营者控制的个人信息，请通过本页第 1 节的真实联系邮箱联系，并说明请求内容。由于应用主要在本机保存数据，部分请求需要用户在自己的设备上删除应用数据或备份；运营者不会要求用户发送数据库、备份 ZIP、密码、Cookie 或完整教务页面。

## 9. 政策变更

如果数据处理方式发生实质变化，运营者会更新本页的版本和日期，并在适用情况下通过应用或 Store 一览告知用户。
