# v0.3.0 验收清单

本清单把本地可重复证据、AppX/MSIX 包证据和 Microsoft Store 外部证据分开记录。**最新候选是 v19**：产品版本 `0.3.0`、Identity Version `0.3.11.0`，路径 `release-v0.3.0-msix-store-v19/college-student-toolkit-0.3.11-x64.msix`，静态包核对通过，SHA-256 `2B16F1E2606A4EFB0E75946F42D7081F4A1BFB8A4B742E80D787D48347341D87`。用户要求停止追加测试，所以下文历史 v14/v15/v18 的 `PASS` 均为历史证据，不能被解释为 v19 的最终回归或 Store 验收。v19 未签名，已上传至 Partner Center Submission 1 草稿并显示 `0.3.11.0` x64；当前无包身份验证错误。`runFullTrust` 审批、商店资料、认证、真实安装更新卸载和真实业务导入都仍未完成。没有这些外部证据时，不能把版本称为 Microsoft Store Stable。

状态定义：

- `PASS`：当前工作区已有可重复证据；
- `PARTIAL`：代码或前置检查完成，但完整环境验收未完成；
- `TODO`：需要发布 runner、干净机器、外部服务或用户本人操作；
- `BLOCKED`：缺少该项时不得宣称 Microsoft Store `v0.3.0 Stable`。

## F. Microsoft Store Stable 放行条件

只有以下项目全部关闭，才可以把版本称为 Microsoft Store `v0.3.0 Stable`：

1. A 区域质量门禁和覆盖率要求达到计划目标，所有 P0/P1 缺陷关闭。
2. B 区域数据库迁移、v1/v2 跨 profile 恢复和 packaged CRUD 通过。
3. C 区域真实日志/远程页面/隐私审计通过，SecAudit 无高危。
4. D 区域最终 OCR 资产、通知、Store 更新和离线/取消回归通过。
5. Windows 11 24H2、25H2 的干净安装、覆盖升级、卸载和重装恢复通过。
6. Partner Center identity 与 manifest 精确一致，最新候选包已上传、审核通过并公开可安装。
7. 用户本人在不保存凭据的前提下完成真实教务系统课程、考试、实验导入。

在上述条件完成前，发布名称保持为“v0.3.0 本地 RC / Microsoft Store 提交候选”，不把 `CN=ms` 本地包或 Partner Center 草稿标记为 Store Stable。
