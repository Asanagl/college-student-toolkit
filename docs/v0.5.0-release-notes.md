# 大学生工具组 v0.5.0 Release Notes

版本：`0.5.0`
状态：`PARTIAL`（源码、类型、lint、格式、单元测试、本地 AppX、隔离 smoke 和 packaged E2E 已验证；正式 Store 提交和 Windows 实机验收待完成）

## 本版本变化

### ACM 工具集

- 新增独立的“ACM 临时 IDE”页面：支持单文件 C++17 编辑、基础模板、stdin、编译/运行、终端 stdout/stderr，以及用户选择或内置的 MinGW 工具链。
- 新增独立的“ACM 对拍”页面：两个编辑器分别输入标准程序和待测程序；用户在当前页面输入一份 stdin，程序按“标准程序编译/运行 → 待测程序编译/运行”的顺序执行。
- 标准程序未正常结束时显示“标准程序失败 / 对拍无效”，不把待测程序标记为 AC 或 WA；只有标准程序正常结束后才比较待测程序结果。
- 比较器按 token 比较，默认忽略行尾空格、连续空白和末尾换行等格式差异；差异视图显示两侧输出、首个差异附近前后各 3 个 token，以及一侧提前结束时的缺失/多余 token。
- ACM 源码、stdin、脏状态和编辑器标签只保存在当前页面会话。关闭或刷新页面后丢弃；Workbench 提供打开文件、保存、另存为和只读/外部变更保护。
- 编译或运行结束后会清理临时目录和可执行文件；清理失败先返回程序比较结果，再显示清理警告并进行有限次数后台重试。
- Windows packaged Runner 优先使用 x64 Job Object helper；开发环境或缺少 helper 时使用受限的 `taskkill` fallback。Runner 不提供操作系统级沙箱，不应运行不受信任的代码。

### 首次使用引导

- 新的空 profile 首次打开时显示四步欢迎页，可选择“开始使用”或“跳过引导”。
- 已有课程、日程、考试、实验、成绩或非默认设置的升级 profile 不会被引导打断。
- 完成/跳过标记写入当前设备的 `onboarding-state.json`，不进入备份；用户主动打开 ACM 设置、插件被禁用或版本升级时，ACM 提示仍按原有版本规则重新显示。
- 引导结束后进入默认的 `/schedule` 空白首页。应用不会因为引导自动创建课程、成绩或教务登录会话。

### 数据、隐私和迁移

- 保留 v0.2 数据库和 legacy v1 备份迁移；便携设置继续使用当前 v2 `acm` 字段兼容规则。
- ACM 源码、标准输入和待测输入不是跨页面持久化数据，也不进入备份；备份仍可能包含课程、考试、实验、成绩、GPA、通知和用户选择的背景图。
- 教务导入仍须用户主动打开并登录；仓库测试只使用脱敏 fixture，不保存真实账号、密码、Cookie、成绩明细或完整页面内容。
