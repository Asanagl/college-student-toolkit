### 产品功能

- 课程表：按周查看课程、周次、节次、教师和地点
- 日程：月历视图、重复日程、提醒和免打扰汇总
- 考试与实验：手动记录、导入、冲突处理和提醒
- 成绩与 GPA：成绩管理、学分加权 GPA 和受限公式编辑
- 数据与备份：v0.2 迁移、v1/v2 备份导入、预检、回滚和恢复
- 教务导入：隔离浏览器、DOM 解析和可选本地 OCR

### Features

- Weekly timetable with weeks, periods, teachers, and locations
- Calendar schedules with reminders, recurring events, and do-not-disturb summaries
- Exam and lab records with import and conflict handling
- Grade management with weighted GPA and restricted formula editing
- Backup inspection, migration, rollback, and recovery
- Isolated academic-system import with DOM parsing and optional local OCR
