## 主要变化

### 数据安全和迁移

- 新库和 v0.2 数据统一迁移到 database schema 2。
- 默认 GPA 公式修正为学分加权公式：

  `SUM(credit * gradePoint) / SUM(credit)`

- 对损坏数据库、未知结构和未来 schema 拒绝继续启动，避免用空库覆盖原数据。
- 新增 v2 备份，包含数据库、便携设置和可选背景图。
- v2 导入先预检，再由用户确认提交；导入过程使用 staging、一次性 token、journal、恢复点和自动回滚。
- 保留 legacy v1 导入兼容；v1 只替换业务数据库，目标机器当前设置保持不变。

### 统一设置和提醒

- 外观入口升级为六页签设置：课程与学期、通知、外观、OCR 组件、数据与备份、关于与更新。
- 学期起始日期不再依赖旧的硬编码日期；未设置时课程提醒暂停并提示用户。
- 日程、课程、考试、实验使用统一提醒调度器，持久化去重状态并支持免打扰汇总。

### 教务导入和 OCR

- 教务远程页面改为独立 `WebContentsView`，本地工具栏不再依赖跨域 iframe。
- 远程页面启用 sandbox、context isolation 和 webSecurity，关闭 node integration，不加载主应用 preload。
- 默认只允许 HTTPS；HTTP 导航、重定向和新窗口均遵守一次性确认策略。
- 关闭导入窗口后清理临时 session、Cookie、缓存和远程 view；已提取的 DOM/截图为完成当前导入暂时保留在主进程内存，下一次导入或应用退出时清空。
- OCR 改为可选组件：启动不自动下载或预加载；用户点击安装后才访问固定 GitHub Release 资产。
- OCR 下载采用压缩包 hash、解压文件 hash、大小限制、取消和原子安装；缺失/损坏时返回稳定错误码，DOM 和手动录入仍可用。

### 输入校验和安全

- 所有主要 IPC 输入在主进程使用 zod 运行时校验，校验日期、时间、范围、长度、ID、base64 和对象结构。
- IPC 错误统一转换为结构化结果，避免异常 rejection 穿过 preload bridge。
- 移除了渲染层任意路径备份导入/导出接口，文件路径由主进程原生对话框管理。
- GPA 公式不再使用有已知高危漏洞且无上游修复的 `expr-eval`；改用共享的受限解析器，拒绝未声明函数和原型属性。
- React Router 和存在安全公告的传递依赖已升级/锁定到修复版本；`npm audit --omit=dev` 当前为 0 vulnerabilities。

## 备份内容和隐私

v2 备份是未加密 ZIP，可能包含课程、考试、实验、成绩和通知等个人学习数据。请只保存到可信位置。

备份包含：

- 业务数据库；
- 主题、学期起始日期、免打扰、通知历史和外观设置；
- 用户选择且通过校验的背景图片。

备份不包含：

- 账号密码；
- 教务 Cookie、登录会话、浏览器缓存和网页存储；
- 窗口坐标、机器绝对路径、更新缓存；
- OCR 组件和提醒去重状态。

## 升级和降级提示

- v0.2 用户应先导出原始数据和 legacy v1 备份，再进行 v0.3 升级。
- 覆盖升级应保留原 userData，并在启动时执行 schema/设置迁移；Store 安装路径下的实际保留行为需要 Windows 实机确认。
- v0.3 v2 备份不能由 v0.2 读取。不要用 v0.2 打开或覆盖 v2 数据；降级前保留原始数据库和旧版备份。
- Store 版本由 Microsoft Store 管理后续更新；不要为 Store 包配置 GitHub updater。
