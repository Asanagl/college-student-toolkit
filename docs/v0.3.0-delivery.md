## 本轮修复的高风险路径

- 备份导出拒绝覆盖 `data.db`、设置、背景、恢复目录和 staging 目录，并先写临时归档再替换最终文件。
- 导入替换失败且回滚失败时保留 journal、staging 和恢复点；下一次启动会进入受控恢复，而不是删除唯一恢复证据。
- OCR 初次因组件缺失失败后，不再缓存失败的初始化 Promise；安装或移除组件会使已有 worker 失效。
- 课程、考试和实验导入不再为缺失日期、时间、周次或节次编造默认业务数据；用户必须在冲突窗口中补全关键字段后才能写入。
- Store 渠道退出时不再触碰 `electron-updater` 的惰性 getter；AppX 校验器同时核对实际可执行文件、精确 SQLite binding 路径和包根更新元数据。
