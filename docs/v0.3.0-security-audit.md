# v0.3.0 v19 聚焦安全审计记录

本记录不是完整 OWASP/CodeQL 审计报告；它只记录 v18 打包前重新核对的安全边界和本轮修复。

- 远程导入浏览器保持隔离 session、sandbox、协议/下载/弹窗/权限拦截和大小限制。
- 背景图与备份背景继续使用受控目录、文件名限制、大小限制和文件头校验。
- 备份导出新增受保护目标拒绝，避免用户错误选择应用数据库、设置、背景、恢复或 staging 路径时覆盖应用数据。
- 备份替换失败不再清除恢复 journal/staging，避免故障恢复路径被提前删除。
- OCR 组件仍以固定 HTTPS Release 资产、固定真实 GitHub CDN 重定向 host/path、压缩/解压双哈希和原子替换管理；本轮还修复了安装后同进程重试。
- MSIX 静态验证要求清单 executable 实际存在、SQLite binding 位于固定路径且为 x64、包内没有 `app-update.yml`。
- Store 更新渠道在代码上不初始化 updater；这不等于实际 Store 进程/审核证明。
- 提醒状态独立保存在 `reminder-state.json`，不进入 v2 备份；扫描游标、失败 retry 和预占去重键用于防止休眠/并发重复通知。

未执行：CodeQL、全依赖动态扫描、渗透测试、真实教务系统登录测试和 Store 端审核。这些未执行项不能被本记录解释为“无漏洞”。
