## 中文（zh-CN）

### 标题

大学生工具组

### 简短描述

管理课程与学习安排，并用本地 ACM 工具练习 C++、编译运行和对拍。

### 详细描述

大学生工具组是一个本地优先的 Windows 学习工作区，帮助你集中维护日程、课程表、考试、实验、成绩和 GPA。

v0.5.0 新增面向校内 ACM 成员的工具集：

- ACM 临时 IDE：编辑单文件 C++17，提供模板、stdin、编译/运行、终端输出和本地 MinGW 探测；
- ACM 对拍：分别输入标准程序和待测程序，按顺序运行，忽略常见空白格式差异，按 token 显示两侧输出和差异片段；
- 标准程序失败时明确显示“对拍无效”，不会把待测程序误判为 AC 或 WA；
- 打开文件、保存、另存为、只读和外部文件变更保护，适合临时练习和本地调试。

首次打开新的空工作区时，应用会显示可跳过的快速引导。已有学习数据的升级用户不会被打断。学习数据保存在本机；ACM 编辑器中的源码和输入只保留在当前页面，关闭或刷新页面后丢弃。

课程表、考试和实验支持用户主动发起的教务导入。远程教务登录由用户本人完成，应用不会在没有用户操作时读取或保存教务账号、密码、Cookie 或登录会话。OCR 组件是可选安装项。

## English (en-US)

### Title

College Student Toolkit

### Short description

Organize study plans and practice C++ locally with an ACM IDE and differential tester.

### Full description

College Student Toolkit is a local-first Windows workspace for schedules, timetables, exams, labs, grades, and GPA.

Version 0.5.0 adds tools for campus ACM members:

- ACM Workbench for single-file C++17 editing, templates, stdin, compile/run, terminal output, and local MinGW detection;
- ACM Differential Tester with separate reference and candidate editors, ordered execution, whitespace-tolerant token comparison, side-by-side output, and focused difference snippets;
- a clear “reference program failed / comparison invalid” state so a candidate is not incorrectly labeled AC or WA;
- open, save, save as, read-only handling, and external-file change protection for temporary practice files.

A new empty workspace shows a skippable first-use guide. Existing profiles with study data are not interrupted. Study data stays on the local device. ACM source code and stdin remain only in the current page session and are discarded when that page is closed or refreshed.

Academic-system import is user initiated. Users log in themselves; the app does not silently collect or persist academic credentials, cookies, or sessions. OCR is an optional component.
